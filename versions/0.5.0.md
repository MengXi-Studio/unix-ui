# @meng-xi/unix-ui v0.5.0 发布：颜色选择器 / 复选框 / 悬浮按钮 / 日期横条，组件总数达到 46

> v0.5.0 是一次组件规模显著扩张的功能版本：新增颜色选择器三件套、复选框四组件、悬浮按钮双组件与日期横条（共 10 个组件目录，组件总数达到 46），同时把散落在 m-calendar 里的日期逻辑抽成 69 个纯函数的日期工具集。修复 m-tabs 平分模式首帧底部条未定位（[#10](https://github.com/MengXi-Studio/unix-ui/issues/10)）与 m-popup 微信小程序端第二次打开无滑入动画（[#11](https://github.com/MengXi-Studio/unix-ui/issues/11)），并解决 Android 云打包暴露的空联合类型数组编译失败。

## 一、这次补的是「表单 + 反馈 + 工具」

0.4.x 的迭代重点在导航与小程序适配，0.5.0 回过头补齐表单拼图——四组新组件恰好覆盖四类长期缺口：

| 新增 | 解决的问题 |
| --- | --- |
| m-color-picker / -popup / -input | 颜色取值没有统一控件，业务里各自拼 RGB 输入框 |
| m-checkbox-group / m-checkbox / -popup / -input | 多选场景缺「组容器 + 弹层 + 输入框」组合形态 |
| m-fab / m-fab-item | 页面级悬浮入口需要自己写定位、展开与拖拽 |
| m-date-strip | 横向日期条与日历面板语义不同，日历塞不进横滑场景 |

四组组件沿用既有的「面板 / 弹出框 / 输入框」拆分惯例：面板负责交互，弹层负责确认语义，输入框负责触发器与回显——与日历三组件保持一致，减少使用时的认知切换。

## 二、新组件逐个讲（带代码）

### 颜色选择器三件套

`m-color-picker` 由饱和度-明度面板、色相条与透明度条组成，`v-model:value` 以字符串受控：

```html
<m-color-picker v-model:value="color" format="hex" :show-alpha="true" />
```

- `format` 支持 `hex` / `rgb` / `hsl`，`show-alpha` 开启后 hex 输出 8 位 `#RRGGBBAA`，传入值兼容 `#RGB` / `#RGBA` / `#RRGGBB` / `#RRGGBBAA` / `rgb()` / `rgba()` / `hsl()` / `hsla()`
- `presets` / `show-presets` 预设色、`show-recent` 最近使用（最多 8 个）、`show-inputs` R/G/B/A 数值输入（失焦提交 + 范围钳制）
- `show-eyedropper` 吸管取色仅在 Web 端渲染（`#ifdef WEB` 内取 `window.EyeDropper`），App / 小程序不渲染入口，不留占位实现
- 面板渐变受 App 端 `background-image` 只支持单层 `linear-gradient` 的约束：改为纯色相层 + 横向白渐变层 + 纵向黑渐变层三个绝对定位节点叠加，而不是写多重背景

`m-color-picker-popup` 维护内部草稿值——确定回写并关闭，取消与遮罩关闭丢弃本次改动；`show-confirm=false` 时选择即生效。`m-color-picker-input` 则是只读触发器 + 左侧色块预览 + 可选字段标签 + 自绘清空。

### 复选框四组件

`m-checkbox-group` 用联合类型数组承载多选值，字符串与数字按字符串化比较（`'1'` 与 `1` 视为同一项）：

```html
<m-checkbox-group v-model:value="checked">
	<m-checkbox name="a" label="选项 A" />
	<m-checkbox name="b" label="选项 B" />
</m-checkbox-group>
```

- `m-checkbox` 双形态：组内按 `name` 参与勾选，独立使用时以 `v-model` 布尔自持
- 支持 `square` 形状、`label-position` 左右互换、`max` 限制、`indeterminate` 不确定横杠、`icon` / `default` 作用域插槽，expose `toggle()` 便于单元格整行切换
- `m-checkbox-popup` 用 options 数组驱动渲染（`field-names` 映射 + footer 插槽），`m-checkbox-input` 以「、」连接回显、超 2 项截断为「等 N 项」

首轮实测抓出两个隐蔽问题：`value instanceof String/Number` 对 UTS 原始值恒为 false（原始值不是包装对象），导致包含判断与 label 回显全空，改为统一 `toString()` 比较；`indeterminate` 最初写成「不确定且已勾选」才显示，实际两者相互独立，未勾选也应显示横杠。

### 悬浮按钮 m-fab / m-fab-item

```html
<m-fab :bottom="120" right="24" draggable magnet="x" v-model:offset="offset">
	<m-fab-item name="分享" icon="share" />
	<m-fab-item name="收藏" icon="star" />
</m-fab>
```

- 四角定位（`top` / `right` / `bottom` / `left`），入口在视口上半侧时向下展开；`background` / `color` 支持渐变，子项未设时继承容器
- 展开按注册序逐项 inline transition（收起逆序），退场总时长播完后才 `v-if` 卸载，快速连点不残留节点
- `draggable` 支持 `axis` 四值限制、`margin-x` / `margin-y` 边界钳制、`magnet` 松手吸附最近边，`v-model:offset` 以入口中心点坐标回写
- `overlay-closable` 展开期间渲染遮罩，点击收起；`entry` / `name` 插槽可完全自定义入口与名称

首版把展开列表用 `position: absolute; right: 0; bottom: 100%` 挂在 48px 的入口节点下，实测列表被包含块钳宽到 76px、圆形按钮被挤到 x=-12、名称气泡被裁——绝对定位元素的 auto 宽会被包含块宽度约束。改为 `position: fixed; left: 0; right: 0` 取视口整宽，再用单侧 padding 把内容顶到入口边缘，名称气泡即可自由向外伸展。

### 日期横条 m-date-strip

```html
<m-date-strip v-model:value="date" value-format="YYYY-MM-DD" show-lunar />
```

- 默认展示今天前 7 天至后 7 天，`type` 支持 `single` / `multiple` / `range`，点选即生效、无确认按钮
- `value-format` 非空时 `v-model:value` 双向绑定字符串，内部经 `parseDate` / `formatDate` 转换，非法字符串按未选中处理
- 超限命名对齐 m-calendar：`max-range` 拒绝并派发 `over-range`（不内置 toast），`allow-same-day` 允许起止同日，端点文案由 `start-date-text` / `end-date-text` / `same-date-text` 定制
- `disabled-date` 灰显禁用并派发 `click-disabled-date`，`filter` 则直接剔除不展示——两种「不可选」语义分开
- `show-lunar` 复用日期工具集在日号下方展示农历；`formatter` 复用 `CalendarDayItem` 契约，另提供 `item` / `top-info` / `bottom-info` 作用域插槽

挂载与外部值变更时会自动把选中项滚到可视区中部，范围两端的色带保持连续。

## 三、日期工具函数集：把日期逻辑从组件里抽出来

新增 `packages/core/utils/date.uts` 公共入口，内部按能力分层为七个纯函数模块（core / compare / arith / boundary / grid / format / lunar），共 69 个具名导出：

```ts
import { formatDate, parseDate, addDays, buildMonthGrid, solarToLunar } from '@/uni_modules/m-ui-x/utils/date.uts'
```

- **基础原语**：归一化、校验、时间戳、闰年、月天数、年内天数
- **比较**：同日 / 同月 / 先后 / 区间 / 今天 / 周末
- **边界与网格**：周月年边界、区间枚举、固定 6×7 月历网格、周序号与季度
- **格式化解析**：13 个基线 token 加 `W` / `Q` / `A` / `a`，`[]` 转义字面量，解析后回校验拦截日期溢出（如 `2026-02-30`）
- **农历**：1900–2100 全量换算（闰月以负数表示）与干支 / 生肖 / 月名 / 日名 / 时辰名

全库统一语义：纯函数不可变、按本地零点计算、失败返回 `null` 而不抛异常。m-calendar 的通用日期函数一并迁入工具集，`calendar.uts` 通过 re-export 保持旧导入路径可用，`m-calendar-popup` / `m-calendar-input` 无需改 import。

工具集为纯函数且写成 TypeScript 严格子集，可搬运到 Node 运行单测；农历 1900–2100 约七万天的一致性不适合人工抽查，这类验证应交给脚本而非演示页。

## 四、实现期的四个坑

**1. Android 空联合类型数组编译失败**：直接把空数组字面量断言为 `CheckboxValueArray` 会生成无类型参数的 `_uA()`，Kotlin 侧报 `Cannot infer type argument for 'E'`。新增 `emptyCheckboxValues()` 工厂统一产出带类型参数的空集合，替换 prop 默认值、上下文初始值与清空事件。同类问题还有日期横条演示页：作用域插槽参数在 Kotlin 侧是 `Any?`，直接访问 `type` / `text` 会 `Unresolved reference`，改为经类型收窄的辅助函数读取。

**2. ucss 不允许后代选择器**：复选框首版写了 `.m-checkbox--label-left .m-checkbox__label`，App 端编译直接报 `Invalid selector`。改为扁平修饰类加 inline labelStyle（左右位置对调 margin），并在禁用态同样使用扁平类 `.m-checkbox__icon-wrap--disabled`。

**3. 小程序 setData 合帧吞掉过渡起点**：m-popup 第二次打开无滑入动画——非 Web 端进入态用 `nextTick` 切换，小程序渲染层把间隔过近的两次 setData 合帧，面板起始位与遮罩 `display:none` 移除落在同一帧，没有可插值的起点。改为 50ms 定时，确保起始位先完成一帧绘制；Web 端双 rAF 分支不变。

**4. options 形态的 tabs 首帧底部条贴边**（[#10](https://github.com/MengXi-Studio/unix-ui/issues/10)）：options 形态没有 `m-tab` 子组件，`ctx.items` 恒为空，`watch(ctx.items)` 中的底部条定位不会触发；初始激活索引与解析结果相同也不会触发 `watch(activeIndex)`，`lineLeft` 保持初值 0，首屏底部条贴在标签栏最左缘。`onMounted` 在初始激活解析与渲染集合初始化后补一次 `nextTick` 首定位，首次直接落位不播动画。

- **待补测**：日期横条的浏览器交互回归（演示页矩阵已就位：single / multiple / range、超限、同日、禁用、过滤、value-format、农历、formatter）
- **构建与一致性**：`pnpm sync:uni-modules:check` 通过，`pnpm build:docs`（VitePress 死链检查）通过
- **Android**：空联合类型数组与日期横条插槽参数导致的云打包编译失败已修复；真机交互（吸管取色、拖拽手感、渐变分层、展开动画帧率）待复测
- **未实测**：iOS / HarmonyOS / 小程序端四组新组件

## 六、从 0.4.2 升级

```bash
pnpm add @meng-xi/unix-ui@latest
# 将包内容拷贝覆盖 uni_modules/m-ui-x
```

- **无破坏性变化**：四组组件均为新增，既有 API、事件与主题变量不变；m-calendar 的内部日期函数迁移到工具集后通过 re-export 保持旧路径可用
- 新增四段主题变量：`$m-color-picker-*`（55 个）、`$m-fab-*`（20 个）以及 `$m-checkbox-*`（22 个）、`$m-date-strip-*`（15 个），全部 `!default`，在根 `uni.scss` 同名定义即覆盖
