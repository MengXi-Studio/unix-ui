# @meng-xi/unix-ui v0.6.0 发布：日期选择三件套（滚轮年 / 月 / 日）

> v0.6.0 是一次新增组件的功能版本：对标 Vant DatePicker，新增 `m-date-picker`（滚轮面板）、`m-date-picker-popup`（弹层）、`m-date-picker-input`（输入框）三个组件，与既有日历三件套采用同一套「面板 / 弹出框 / 输入框」拆分惯例。组件值口径为 `Date`，与 `m-calendar` 保持一致。

## 一、为什么又是三件套

Vant 的 DatePicker 是单组件，弹层场景需要自行组合 `van-popup`。本项目在日历上已经验证过「面板 / 弹层 / 输入框」三分的收益：面板只负责选择状态，弹层只负责显隐与动效，输入框只负责触发器与回显，职责单一、可分别复用。

日期选择沿用同一结构：

| 组件 | 职责 |
| --- | --- |
| `m-date-picker` | 年 / 月 / 日滚轮列、区间收敛、过滤格式化、顶部栏 |
| `m-date-picker-popup` | `m-popup` + 面板，确认 / 取消后自动关闭 |
| `m-date-picker-input` | `m-input` + 弹层，只读触发、确认回填、自绘清空 |

## 二、面板：m-date-picker

```html
<m-date-picker v-model:value="date" title="选择日期" @confirm="onConfirm" />
```

- `columns-type` 支持 `year` / `month` / `day` 任意顺序组合：`['year']`、`['year','month']`、`['month','day']` 均可；未包含的分量按 1 月 1 日归一（年-月组合的日为 1 号，月-日组合沿用当前年份）
- `min-date` / `max-date` 默认前后十年；年界决定月界，已选年月决定日界，越界选择自动收敛
- `filter(type, options, values)` 二次过滤列选项，`formatter(type, option)` 改写选项文案，二者均为同步函数
- `option-height` / `visible-option-num` 控制行高与可视行数；`readonly` 滚轮回弹、`loading` 覆盖并阻断交互
- 顶部栏：`show-toolbar`、`title`、`confirm-button-text`、`cancel-button-text`，`toolbar` / `title` / `confirm` / `cancel` 插槽可整体或分段替换
- 实例方法：`confirm()`、`resetSelection()`、`getSelectedDate()`

滚轮吸附：滚动停止后按 `round(scrollTop / optionHeight)` 吸附到最近选项；`swipe-duration` 是「滚动停止判定时长」。原生 `scroll-view` 的同值属性不会重发，吸附时对同值目标先偏移 0.5px 再归位，确保定位生效。

```html
<m-date-picker :columns-type="['year', 'month']" :filter="halfYearFilter" :formatter="suffixFormatter" />
```

## 三、弹层与输入框

`m-date-picker-popup` 把面板套进 `m-popup`，`confirm` / `cancel` 之后自动派发 `update:show=false`；`reset-on-open` 控制复开时是否复位为 `value`（默认保留上次选择）。

```html
<m-date-picker-popup v-model:show="show" v-model:value="date" title="选择日期" />
```

`m-date-picker-input` 用只读 `m-input` 展示日期，透明触发层接住整区点击打开弹层；展示格式随 `columns-type` 派生（`YYYY` / `YYYY-MM` / `YYYY-MM-DD` / `MM-DD`），清空回写 `null` 并派发 `clear`。

```html
<m-date-picker-input v-model:value="date" :columns-type="['year', 'month']" placeholder="请选择年月" />
```

## 四、实现要点

- **无覆盖遮罩**：uvue 没有 `pointer-events`，Vant 式的渐变遮罩会拦截滚动手势。改为按选项与激活项的距离分三档 `opacity` 渐隐，选中框两条细线放在列层之下（`z-index: 0`）、列层 `z-index: 1`，视觉层次保留且不挡手势。
- **列复用而非新增公共组件**：滚轮列是内部子组件 `m-date-picker-column.uvue`（不注册 easycom），与 `m-calendar-panel` 同一模式，不新增 `m-picker` 对外契约。
- **小程序插槽分叉**：`option` 插槽声明在选项 `v-for` 内，按既有约定 `#ifndef MP` / `#ifdef MP` 分叉，小程序端回退内置文本（LESSONS #17 / #88）。
