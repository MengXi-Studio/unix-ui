# @meng-xi/unix-ui v0.6.0 发布：日期 / 时间 / 通用选择器 / 农历选择

> v0.6.0 是纯新增的功能版本，落地 20 个组件（组件总数从 0.5.0 的 46 增至 65）：日期选择三件套、日期范围三件套、时间选择三件套、时间范围三件套、通用选择器系列（含索引受控纯视图）与农历选择三件套。全部沿用「面板 / 弹出框 / 输入框」三分惯例——面板只管选择状态，弹层只管显隐与动效，输入框只管触发器与回显；同一份选择能力可按场景取用任一形态。同时把 `m-date-picker` / `m-time-picker` 的面板视觉迁到 `m-picker`，对外契约不变。

## 二、日期选择

```html
<m-date-picker v-model:value="date" title="选择日期" @confirm="onConfirm" />
```

- `columns-type` 支持 `year` / `month` / `day` 任意顺序组合；未包含的分量按 1 月 1 日归一（年-月组合日为 1 号，月-日组合沿用当前年份）
- `min-date` / `max-date` 默认前后十年；年界决定月界，已选年月决定日界，越界自动收敛
- `filter(type, options, values)` 二次过滤、`formatter(type, option)` 改写文案，均为同步函数
- `option-height` / `visible-option-num` 调整滚轮；`readonly` 滚轮回弹，`loading` 覆盖并阻断交互
- 顶部栏 `show-toolbar` / `title` / `confirm-button-text` / `cancel-button-text`，配合 `toolbar` / `title` / `confirm` / `cancel` / `columns-top` / `columns-bottom` 插槽
- 实例方法：`confirm()` / `resetSelection()` / `getSelectedDate()`

弹层与输入框分别承接 `v-model:show` 与 `v-model:value`；确认 / 取消后自动派发 `update:show=false`，`reset-on-open` 控制复开时是否复位为 `value`。输入框展示格式随列组合派生（`YYYY` / `YYYY-MM` / `YYYY-MM-DD` / `MM-DD`），清空回写 `null` 并派发 `clear`。

## 三、日期范围 / 时间 / 时间范围

```html
<m-date-range-picker v-model:value="range" :tabs="['入住', '离店']" />
<m-time-picker v-model:value="time" :columns-type="['hour', 'minute', 'second']" />
<m-time-range-picker v-model:value="shift" :tabs="['上班', '下班']" :minute-step="15" min-time="09:00" max-time="18:00" />
```

- 范围面板复用同一套滚轮，两端值分别维护；确认时起点晚于终点自动交换为升序，`change` 派发两端快照与当前编辑端下标
- 时间支持 `minute-step` / `second-step` 步长；`min-time` / `max-time` 同日收敛，单端配置自动补齐，跨天视为不约束
- `hour-cycle` 24 / 12：12 制自动附加「上午 / 下午」列，绑定值仍为 24 小时制
- 插槽：面板 `toolbar` / `title` / `confirm` / `cancel`，范围面板另有 `header`（快捷选项）/ `footer`
- 实例方法：`confirm()` / `resetSelection()` / `getSelectedValue()`

## 四、通用选择器：m-picker

```html
<m-picker v-model:value="line" :columns="lineOptions" title="选择产线" />
<m-picker v-model:value="region" :columns="regionTree" title="选择地区" />
<m-picker-view v-model:value="indexes" :columns="yearMonthDay" />
```

- `columns` 一维按单列（含 `children` 走级联）、二维按多列；运行时自动判别，无需额外开关
- `change` / `confirm` 回传 `(value, selectedOptions, indexes)`，可同时拿到业务值与各列下标
- 禁用项灰显、吸附跳过、点击不选中；列组件新增可选 `disabledOptions`，日期 / 时间不传即行为不变
- `m-picker-view` 无工具栏、不做值换算与级联展开，只按 `number[]` 索引受控渲染，适合嵌在自定义容器内

## 五、农历选择

农历换算原本已在 `utils/date` 中（公历 ↔ 农历、闰月、月长、干支生肖），本轮接到选择器上：

```html
<m-lunar-picker v-model:value="birthday" show-gan-zhi title="选择农历生日" />
```

- 月列是真实农历月序（闰月紧随其月，文案如「闰二月」），日列按农历月长 29 / 30 生成
- 对外值仍是公历 `Date`，`change` / `confirm` 与日期选择器同构，可在同一表单混用
- 年列可按开关附加干支 / 生肖；`min-date` / `max-date` 为公历日期，列边界反向映射到农历，默认覆盖农历表 1900–2100
- `utils/date` 新增导出 `getLunarMonthSequence(year)` / `LUNAR_START_YEAR` / `LUNAR_END_YEAR`

## 六、变更：面板迁移到 m-picker

`m-date-picker` / `m-time-picker` 的顶部栏、选中框、滚轮容器与加载遮罩改由 `m-picker` 承担，自身仅保留列构建与事件回写。

- 对外 props / events / 插槽 / 实例方法全部不变，无 API 变更
- 面板级主题变量收敛为 `$m-picker-*`；`$m-date-picker-*` 仅保留选项文本三项，`$m-time-picker-*` 不再提供面板变量

## 七、实现要点

- **不用覆盖遮罩**：uvue 没有 `pointer-events`，Vant 式的渐变遮罩会拦截滚动手势。改为按选项与激活项的距离分三档 `opacity` 渐隐；选中框两条细线放在列层之下（`z-index: 0`）、列层 `z-index: 1`，视觉层次保留且不挡手势
- **滚轮吸附**：滚动停止后按 `round(scrollTop / optionHeight)` 吸附最近项；原生 `scroll-view` 同值不重发，吸附时先偏移 0.5px 再归位以确保定位生效
- **`option` 插槽仅 Web 生效**：该插槽声明在选项 `v-for` 内。App 端具名插槽解构出的行下标为 `Any?`，传入 `number` 参数无法通过 Kotlin 编译；小程序端同名插槽在 `v-for` 内只生效第一个且触发重复告警。两端均回退内置文本，自定义文案请用 `formatter`
- **列数据用 `any[]` 承载**：`PickerColumns` 若声明为 `PickerOption[] | PickerOption[][]` 联合类型，Kotlin 产物会把 props 的 `type` 编译成空泛型调用并退化为 `Any?`，导致 `.length` / `[i]` 无法访问。改为具体数组类型 + 运行时 `Array.isArray` 判别

## 八、修复

- **`m-input` 在 `m-cell` 内 `inlaid` 高度塌陷**：新增 `$m-input-inlaid-min-height`（默认 `24px`），占位符垂直居中；所有透传 `inlaid` 的输入类组件同步受益
- **`m-input` 在 `m-compact` 水平组合中文字贴顶**：边框容器改为 `flex: 1` 撑满根节点，与同行 `m-button` 等高后文字居中；普通形态与 `textarea` 不受影响
