# @meng-xi/unix-ui v0.6.0 发布：日期选择 / 日期范围 / 时间选择 / 通用选择器系列

> v0.6.0 是一次新增组件的功能版本：对标 Vant DatePicker 新增 `m-date-picker`（滚轮面板）、`m-date-picker-popup`（弹层）、`m-date-picker-input`（输入框）；对标 Sard DatetimeRangePicker 新增 `m-date-range-picker`（范围面板）、`m-date-range-picker-popup`（弹层）、`m-date-range-picker-input`（输入框）；补齐时间维度，新增 `m-time-picker` 三件套与 `m-time-range-picker` 三件套；补齐通用选择能力，新增 `m-picker`（通用选择器）、`m-picker-popup`、`m-picker-input` 与 `m-picker-view` / `m-picker-view-column`（索引受控纯视图）。十四款组件共用同一套「面板 / 弹出框 / 输入框」拆分惯例：日期口径为 `Date`，时间口径为 `'HH:mm'` / `'HH:mm:ss'` 字符串，通用选择器为任意业务值。

## 一、为什么又是三件套

Vant 的 DatePicker 是单组件，弹层场景需要自行组合 `van-popup`。本项目在日历上已经验证过「面板 / 弹层 / 输入框」三分的收益：面板只负责选择状态，弹层只负责显隐与动效，输入框只负责触发器与回显，职责单一、可分别复用。

日期选择沿用同一结构：

| 组件 | 职责 |
| --- | --- |
| `m-date-picker` | 年 / 月 / 日滚轮列、区间收敛、过滤格式化、顶部栏 |
| `m-date-picker-popup` | `m-popup` + 面板，确认 / 取消后自动关闭 |
| `m-date-picker-input` | `m-input` + 弹层，只读触发、确认回填、自绘清空 |

## 二、面板：m-date-picker

```html
<m-date-picker v-model:value="date" title="选择日期" @confirm="onConfirm" />
```

- `columns-type` 支持 `year` / `month` / `day` 任意顺序组合：`['year']`、`['year','month']`、`['month','day']` 均可；未包含的分量按 1 月 1 日归一（年-月组合的日为 1 号，月-日组合沿用当前年份）
- `min-date` / `max-date` 默认前后十年；年界决定月界，已选年月决定日界，越界选择自动收敛
- `filter(type, options, values)` 二次过滤列选项，`formatter(type, option)` 改写选项文案，二者均为同步函数
- `option-height` / `visible-option-num` 控制行高与可视行数；`readonly` 滚轮回弹、`loading` 覆盖并阻断交互
- 顶部栏：`show-toolbar`、`title`、`confirm-button-text`、`cancel-button-text`，`toolbar` / `title` / `confirm` / `cancel` 插槽可整体或分段替换
- 实例方法：`confirm()`、`resetSelection()`、`getSelectedDate()`

滚轮吸附：滚动停止后按 `round(scrollTop / optionHeight)` 吸附到最近选项；`swipe-duration` 是「滚动停止判定时长」。原生 `scroll-view` 的同值属性不会重发，吸附时对同值目标先偏移 0.5px 再归位，确保定位生效。

```html
<m-date-picker :columns-type="['year', 'month']" :filter="halfYearFilter" :formatter="suffixFormatter" />
```

## 三、弹层与输入框

`m-date-picker-popup` 把面板套进 `m-popup`，`confirm` / `cancel` 之后自动派发 `update:show=false`；`reset-on-open` 控制复开时是否复位为 `value`（默认保留上次选择）。

```html
<m-date-picker-popup v-model:show="show" v-model:value="date" title="选择日期" />
```

`m-date-picker-input` 用只读 `m-input` 展示日期，透明触发层接住整区点击打开弹层；展示格式随 `columns-type` 派生（`YYYY` / `YYYY-MM` / `YYYY-MM-DD` / `MM-DD`），清空回写 `null` 并派发 `clear`。

```html
<m-date-picker-input v-model:value="date" :columns-type="['year', 'month']" placeholder="请选择年月" />
```

## 四、实现要点

- **无覆盖遮罩**：uvue 没有 `pointer-events`，Vant 式的渐变遮罩会拦截滚动手势。改为按选项与激活项的距离分三档 `opacity` 渐隐，选中框两条细线放在列层之下（`z-index: 0`）、列层 `z-index: 1`，视觉层次保留且不挡手势。
- **列复用与面板收敛**：滚轮列仍是内部子组件 `m-date-picker-column.uvue`（不注册 easycom）；新增的 `m-picker` 作为通用选择器对外提供，`m-date-picker` / `m-time-picker` 的面板视觉（顶部栏 / 选中框 / 滚轮容器 / 加载遮罩）改为组合 `m-picker`，不再重复自绘。
- **小程序插槽分叉**：`option` 插槽声明在选项 `v-for` 内，按既有约定 `#ifndef MP` / `#ifdef MP` 分叉，小程序端回退内置文本（LESSONS #17 / #88）。

## 八、同版本新增：日期范围三件套

对标 Sard DatetimeRangePicker，范围选择复用上面的日期滚轮，新增三个组件：

| 组件 | 职责 |
| --- | --- |
| `m-date-range-picker` | 开始 / 结束两段标题 + 同一套日期滚轮，维护两端值 |
| `m-date-range-picker-popup` | `m-popup` + 面板，确认 / 取消后自动关闭 |
| `m-date-range-picker-input` | `m-input` + 弹层，只读展示「起 - 止」、确认回填、自绘清空 |

```html
<m-date-range-picker v-model:value="range" :tabs="['入住', '离店']" @confirm="onConfirm" />
```

- 两段标题自绘（`tabs` 可自定义），切换后分别编辑起点 / 终点；`columns-type`、`min-date` / `max-date`、`filter` / `formatter` 全部沿用 `m-date-picker` 契约
- 确认时若起点晚于终点自动交换为升序；change 实时派发两端快照与当前编辑端下标
- 插槽：`header`（快捷选项，如「近一周 / 近一月」）、`title`（整体替换两段标题，作用域 `tabs` / `activeIndex`）、`footer`、`confirm`、`cancel`
- 输入框：`outlet-format` 自定义展示格式，缺省按列组合派生（`YYYY-MM-DD`）；清空回写 `null` 并派发 `clear`
- 实例方法：`confirm()`、`resetSelection()`、`getSelectedValue()`
- 首版仅年 / 月 / 日粒度，不包含时 / 分 / 秒与农历

## 九、同版本新增：时间选择三件套

日期之外补齐时间维度，新增 `m-time-picker` / `m-time-picker-popup` / `m-time-picker-input` 与 `m-time-range-picker` / `m-time-range-picker-popup` / `m-time-range-picker-input`，滚轮列直接复用日期选择的列子组件。

```html
<m-time-picker v-model:value="time" :columns-type="['hour', 'minute', 'second']" />
<m-time-range-picker v-model:value="range" :tabs="['上班', '下班']" :minute-step="15" min-time="09:00" max-time="18:00" />
```

- `columns-type` 支持时 / 分 / 秒任意组合（默认时 : 分），值按 24 小时制输出 `'HH:mm'` / `'HH:mm:ss'`
- `minute-step` / `second-step` 支持步长；`min-time` / `max-time` 按同日收敛时列，边界小时再收敛分 / 秒列
- `hour-cycle` 支持 24 / 12：12 制自动附加「上午 / 下午」列，绑定值仍为 24 小时制
- 时间范围两端共用列组合 / 步长 / 区间 / 制式，确认时自动交换为升序
- 插槽：`toolbar` / `title` / `confirm` / `cancel` / `option`；范围面板另有 `header` / `footer`
- 实例方法：`confirm()`、`resetSelection()`、`getSelectedValue()`

## 十、同版本新增：通用选择器系列

面向任意业务选项（产线、班次、地区等）的通用滚轮选择器，一维 / 二维列数据自动识别，支持 `children` 级联与禁用项。

```html
<m-picker v-model:value="line" :columns="lineOptions" title="选择产线" />
<m-picker v-model:value="region" :columns="regionTree" title="选择地区" />
<m-picker-popup v-model:show="show" v-model:value="date" :columns="yearMonthDay" />
<m-picker-input v-model:value="shift" :columns="shiftOptions" />
<m-picker-view v-model:value="indexes" :columns="yearMonthDay" />
```

- `columns` 一维按单列（含 `children` 走级联）、二维按多列；值口径：单列标量、多列 / 级联数组
- 事件回传 `(value, selectedOptions, indexes)`，可同时拿到原始选项与各列下标
- 禁用项：灰显、滚动吸附跳过、点击不选中（列组件新增可选 `disabledOptions`，日期 / 时间不受影响）
- 插槽：`toolbar` / `title` / `confirm` / `cancel` / `option` / `columns-top` / `columns-bottom`
- `m-picker-view` 为无工具栏、索引受控纯视图，`m-picker-view-column` 可单独使用
- 实例方法：`confirm()`、`resetSelection()`、`getSelectedValue()`、`getSelectedIndexes()`
