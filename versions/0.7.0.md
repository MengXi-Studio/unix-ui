# @meng-xi/unix-ui v0.7.0 发布：数字键盘 / 密码输入 / 单选 / 评分 / 搜索 / 分段控制器 / 列表选择

> v0.7.0 是纯新增的功能版本，落地 14 个组件（组件总数从 0.6.0 的 65 增至 79）：数字键盘面板与弹层、密码输入格子与弹层、单选框四件套、评分、搜索、分段控制器、列表选择三件套。同时完成两轮 Android 云打包 Kotlin 编译错误修复，并补齐若干既有组件的实际表现问题。

| 分组 | 组件 | 职责 |
| --- | --- | --- |
| 数字键盘 | `m-number-keyboard` | 1-9 + 0 + 删除键的纯按键区，不持值，只派发 `input` / `delete` / `close` |

## 二、数字键盘与密码输入

```html
<m-number-keyboard type="random" theme="custom" @input="onInput" @delete="onDelete" @close="onClose" />
<m-number-keyboard-popup v-model:show="show" title="请输入" @input="onInput">
  <view class="code-cells">...</view>
</m-number-keyboard-popup>
<m-password-input-popup v-model:show="show" v-model:value="code" :length="6" />
```

- `type` 支持 `number` / `digit` / `idcard` / `random`（`random` 挂载与切换时重排，也可调用 `shuffle()` 手动重排）
- 无额外键时 `0` 加宽占两格填满末行；`digit` / `idcard` 或自定义 `extra-keys` 时额外键位于末行左侧
- `theme="custom"` 用右侧栏替代末行删除键，删除键与关闭键上下平分高度
- `disabled-key` 回调返回 `true` 的键灰显且不派发事件；`extra-key` 插槽自定义额外键
- 弹层未传默认插槽时不渲染内容区；`show-toolbar` / `show-cancel` / `show-confirm` 控制工具条，取消 / 完成派发后自动关闭
- 密码格子：`bordered`（圆角方框）/ `underlined`（仅底部 1px 底线）；`mask` 圆点、`plain-text` 明文；`focused` 驱动当前位闪烁光标与高亮边框；`info` / `error-info` 提示文字（error 优先）
- 密码弹层：输入自动收敛 `maxlength=length`，打开自动聚焦，`keyboard-type="random"` 每次打开重新打乱，填满后数字键自动禁用

## 三、单选框四件套

```html
<m-radio-group v-model:value="picked" :options="options" />
<m-radio-popup v-model:show="show" v-model:value="picked" :options="options" title="选择产线" />
```

- 值类型为 `RadioValue | null`（`null` 未选），无 `any`
- 图标为自绘 view：`round` 外环 + 内实心圆点、`square` 方框 + 内圆点，跨端渲染一致
- 禁用态用外环灰底填充 + 灰点表达；选中态退灰不再用主题色
- `label-position` / `label-disabled` / `icon-size` / `checked-color` / `direction` / `icon` 与 `default` 插槽与 checkbox 系对齐
- 独立使用为受控 `checked` prop；点已选项不取消（单选刚性）
- 弹层点选后不自动关闭（受控模型，需即选即关可监听 `change`）；输入框自绘清空按钮回写 `null` 并派发 `clear`

## 四、评分 m-rate

```html
<m-rate v-model:value="score" allow-half clearable @change="onChange" />
```

- `v-model:value` 绑定 `number`（0 = 未评分），交互分值吸附 0.5 网格
- 单颗星由「未选字形 + 宽度百分比裁切层」叠成，`allow-half` 裁切 50% 实现半星
- `readonly` + `allow-half` 按小数位裁切，可展示 `3.3` 这类任意小数
- `icon` / `void-icon` 接 m-icon 字形名（默认 `star` / `star-o`）并提供同名插槽（作用域 `{ index, active }`）
- `count` / `size` / `gap` / `color` / `void-color` / `disabled-color` 定制视觉
- `clearable` 再次点击当前分值清零；`touchable` 默认开启，按住横向拖动连续选分
- MP 端 `v-for` 内不声明同名插槽，回退内置字形

## 五、搜索 m-search

```html
<m-search v-model:value="keyword" show-action action-type="search" @search="onSearch" />
```

- 组合 `m-input`（inlaid 形态）承载输入 / 清空 / 聚焦 / 只读禁用 / 格式化，自身负责搜索框外观
- `v-model:value` 绑定输入值，`change` 值变即派发；键盘确认键派发 `search`
- `shape`（round）+ `background` / `input-background` 定制外观
- `label` / `left-icon`（默认 search）/ `right-icon` + 同名插槽承载框内元素
- `show-action` + `action-text` + `action-type`（cancel / search）统一右侧按钮，`action` 插槽接管后不再自动派发
- `error` / `error-message` 渲染红框与提示行；`left` / `action` 外部插槽；实例方法 `focus()` / `blur()`

`m-input` 同版本增强（纯新增，默认行为不变）：`confirm` 事件（键盘确认键回传当前值）与 `input-align`（`left` / `center` / `right` 输入文字对齐）。

## 六、分段控制器 m-segmented

```html
<m-segmented v-model:value="shift" :options="shiftOptions" />
<m-segmented v-model:value="tab" :options="tabs" direction="vertical" shape="round">
  <template #item="{ option, active }">...</template>
</m-segmented>
```

- `options` + `fieldNames` 驱动的等分单选，`v-model:value` 受控
- `size` 三档 / `shape` 胶囊 / `direction` 纵向全量支持
- 选中滑块按等分百分比定位，切换走 `UniElement.animate` 平移（小程序端直接落位），`duration` 可关闭
- `item` 作用域插槽（`{ option, index, active, disabled }`）支持图标 + 文本 / 仅图标
- `ellipsis` 默认单行省略；组件级 `disabled` / 选项级 `disabled` / `readonly` 三态语义明确；同值点击不派发事件

## 七、列表选择三件套

```html
<m-select v-model:value="line" :options="options" filterable @change="onChange" />
<m-select v-model:value="lines" :options="options" multiple :multiple-limit="2" show-toolbar />
<m-select-input v-model:value="line" :options="options" title="选择产线" clearable />
<m-select-popup v-model:show="show" v-model:value="line" :options="options" title="选择产线" />
```

- `options` 驱动，含 `children` 的项渲染为分组标题，子项可选；`option` 作用域插槽自定义整项
- `filterable` 本地包含匹配筛选；`filterMethod` 远程受控筛选（`v-model:filter-value`）
- 多选：`multiple` / `multiple-limit`（0 不限）/ `show-toolbar`（已选数量 + 清空）；多选时 `value` 为数组，点击已选项取消，达上限后其余项不可选
- 多选弹层选中不自动关闭（`confirmOnSelect` 仅对单选生效）
- 输入框标签按 `options` → `map-label` → 值字符串解析，`max-labels`（默认 10，-1 不限）折叠为「等 N 项」
- 实例方法 `scrollTop()` 回顶；整体 / 单项禁用、空态文案、选中态勾选图标齐全

## 八、修复

- **`m-input` 在 `m-cell` 内 `inlaid` 值区不拉伸**：inlaid 根节点新增 `flex-grow: 1`（`flex-basis` 保持 `auto`），body / 控件填满 value 区，标题与输入框之间的空隙可点击；演示页移除用户侧 `custom-style="flex: 1"` 补偿
- **`m-checkbox` 未选中态误渲染为实色勾**：未选与选中曾共用同一个 `m-icon 'success'` 字形（字体修复前字形缺失，未选态碰巧看着像空框）。未选改为标准描边空框，选中为实心填充 + 白勾，`indeterminate` 为实心底 + 白横杠
- **微信小程序端打开 `m-color-picker-popup` 抛 `reading 'proxy'`**（issue #20）：`measureNode` 在调用时取 `getCurrentInstance()`，经父组件 `$callMethod('refresh')` 调用时已脱离 setup 上下文返回 `null`。改为 setup 期一次性捕获实例（`#ifdef MP`）；`m-rate` 同类调用一并修正
- **Android 云打包 Kotlin 编译错误第一轮**：`m-calendar` watch 回调移至 `getSelectedDate` 之后；`m-input` focus / blur 公共处理移至四个原生事件桥接函数之前；`m-toast` 关闭流程函数前移 + `custom-class` 显式 `as string`；`m-calendar-input` 演示页 `fmtDate` 前移；`m-calendar` 工具 `hexDigitValue` 对 `charCodeAt` 空值先行短路；`m-row` 行分组首组显式类型声明
- **Android 云打包 Kotlin 编译错误第二轮**（5 组件 + 6 演示页，Web 端行为不变）：
  - Kotlin 局部函数禁前向引用——`m-select` 的 `selectedValues` / `containsValue` / `isSelected`、`m-select-input` 的 `labelOf`、`m-password-input` 的 `stopCursorAnimation` 均调整到调用者之前
  - type alias 与数组联合的组合形参（`RadioValue | RadioValue[]`）会让 codegen 静默丢弃整个函数——`m-select-input` / `m-select-popup` 的透传函数形参展开为 `string | number | string[] | number[]`，事件绑定由函数名直传改为内联 `$event` 调用
  - watch 单表达式 source 补显式返回类型注解；`m-number-keyboard-popup` 的 `$slots.default` 改索引访问（`default` 为 Kotlin 保留字）
  - 演示页（rate / search / segmented / select / select-input / select-popup）事件日志形参放宽为 `any | null`、插槽作用域变量经页面函数内部 cast、`valuesText` 声明前移

## 九、实现要点

- **光标闪烁不用 DOM 动画**：`el.animate` 在 Web 端不存在、`el.style.setProperty` 在 web 端 `UniElement` 代理上无效，改为 `setInterval` 半周期切换响应式 class，全平台一致
- **watch getter 只返回单值**：`watch((): [boolean, number] => [...])` 会被翻译成非法的 Kotlin `fun(): [Boolean, Number]`，云打包直接失败；拆成两个单值 watch 共用同步函数（Web 完全无法暴露该问题）
- **函数声明顺序按调用依赖拓扑排**：UTS 函数声明有提升，但 codegen 按源码顺序生成 Kotlin 局部函数，先使用后声明即 `Unresolved reference`
- **事件透传函数形参避开「type alias + 数组联合」**：该组合让 codegen 静默丢弃整个函数，渲染层表现为 `Function invocation expected`；展开成具体联合类型即可
- **`$slots.xxx` 一律索引访问**：`default` 等 Kotlin 保留字用属性访问时反引号转义失效
- **多选数组判别用 `typeof`**：`Array.isArray` 在 Kotlin 端无法推断泛型参数

## 十二、从 0.6.0 升级

```bash
pnpm add @meng-xi/unix-ui@latest
# 将包内容拷贝覆盖 uni_modules/m-ui-x
```

无可感知的破坏性变更：仅新增组件与新增主题变量段；`m-input` 的 `confirm` / `input-align` 为纯新增（默认行为不变）；既有组件的 props / events / 插槽与主题变量默认值均未改动。

新增变量段：`$m-number-keyboard-*` / `$m-password-input-*` / `$m-radio-*` / `$m-rate-*` / `$m-search-*` / `$m-segmented-*` / `$m-select-*` / `$m-select-toolbar-*`，以及 checkbox 修复新增的 `$m-checkbox-box-border-color` / `$m-checkbox-box-border-width` / `$m-checkbox-box-radius` / `$m-checkbox-check-icon-size`。
