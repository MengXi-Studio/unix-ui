# @meng-xi/unix-ui v0.8.0 发布：手风琴 / 签名 / 滑动条 / 步进器 / 开关 / 文件上传

> v0.8.0 是纯新增的功能版本，新增 7 个组件：手风琴容器与面板、手写签名、滑动条、步进器、开关、文件上传。
> 同时修复微信小程序日期滚轮列不渲染（[issue #31](https://github.com/MengXi-Studio/unix-ui/issues/31)）、
> 清理 Android 云打包的 Kotlin 编译错误，并把 30 余处文档与源码不一致的 API 说明对齐。无破坏性 API 变更。

## 一、组件全景

| 分组 | 组件 | 职责 |
| --- | --- | --- |
| 数据展示 | `m-accordion` | 手风琴容器，`v-model:value` 绑定展开标识数组，受控 / 非受控双支持 |
| 数据展示 | `m-accordion-item` | 手风琴面板，头部点击恒派发 `click`，`arrow` 插槽可自定义指示器 |
| 数据录入 | `m-signature` | Canvas 手写签名，撤销历史 + PNG 导出，支持全屏签名 |
| 数据录入 | `m-slider` | 滑动条，单值 / 范围、横纵方向、值气泡与刻度 |
| 数据录入 | `m-stepper` | 步进器，长按连续增减、`before-change` 同步或异步校验 |
| 数据录入 | `m-switch` | 开关，`before-update` 异步切换自动接管 loading |
| 数据录入 | `m-uploader` | 文件上传，选择 / 预览 / 上传进度 / 失败重传 / 长按排序 |

```html
<m-accordion v-model:value="active" multiple inset>
  <m-accordion-item title="面板一" name="a">内容</m-accordion-item>
  <m-accordion-item title="面板二" name="b">内容</m-accordion-item>
</m-accordion>

<m-signature @submit="onSubmit" />
<m-slider v-model:value="price" :min="0" :max="100" show-scale />
<m-stepper v-model:value="count" :min="1" :max="9" />
<m-switch v-model:value="enabled" :before-update="beforeUpdate" />
<m-uploader v-model:value="files" upload-url="https://example.com/upload" />
```

## 二、重点能力

**m-accordion / m-accordion-item**

- `multiple` 多开、`disabled` 全局禁用、`hide-border` 隐藏分隔线、`inset` 圆角卡片；
- `duration` 展开收起高度过渡（0 表示直接显隐）、`lazy-render` 首次展开才渲染内容；
- 未传 `value` 时容器自持状态，`name` 缺省按注册序兜底；组内末项自动隐藏分隔线；
- expose `open()` / `close()` / `toggle()` / `closeAll()`；
- 插槽：`title` / `extra` / `arrow`（作用域参数 `visible`）。

**m-signature**

- `pen-color` / `line-width` / `history-size` / `background-color`，撤销后整幅重绘；
- `full-screen` + `v-model:visible` 全屏签名，取消派发 `cancel`；
- 事件 `start` / `signing` / `end` / `submit` / `clear` / `cancel`，`submit` 返回 `{ image }`（PNG dataURL）；
- expose `resize()` / `clear()` / `undo()` / `submit()`；
- uni-app x 的 `toDataURL()` 不接收参数，因此不提供 `type` / `quality`，统一输出 PNG。

**m-slider**

- `v-model:value` 支持 `number` 与 `number[]`，`range` 双滑块、`vertical` / `reverse`；
- `min` / `max` / `step`，值按 step 对齐并夹取，范围模式两值不允许交叉；
- `show-value` 值气泡、`show-scale` 刻度，位置四向可调；刻度过多时只画刻度线不画文字；
- 插槽：`button` / `left-button` / `right-button`（作用域含 `value` / `dragging`）；
- 事件：`change` / `drag-start` / `drag-end`。

**m-stepper**

- `v-model:value`（`number`），`min` / `max` / `step` / `decimal-length` / `integer`；
- `allow-empty` + `value-on-clear`、`auto-fixed`；`disable-plus` / `disable-minus` / `disable-input`、`show-*`；
- 长按连续增减（`press-time` / `interval`），`before-change` 支持同步返回值或 Promise；
- `theme="round"` 与 `variant` / `size`。

**m-switch**

- `v-model:value` 支持 `boolean` / `string` / `number`，`checked-value` / `unchecked-value` 自定义值口径；
- `disabled` / `readonly` / `loading`，`active-color` / `inactive-color` / `size`；
- `before-update` 异步切换期间自动进入 loading 并派发 `update:loading`；
- 插槽：`checked-text` / `unchecked-text` / `node` / `background`。

**m-uploader**

- `v-model:value` 绑定图片 / 视频对象数组，`media-type` / `multiple` / `max-count` / `max-size` + `oversize`；
- `upload-url` 非空时内置 `uni.uploadFile` 并回填状态与进度，为空只派发 `after-read`；
- `setItemStatus()` 回写状态，失败项点击重传，`sortable` 长按拖拽排序；
- `before-choose` / `before-read` / `before-delete` 支持同步或 Promise；
- expose `choose()` / `clear()` / `abort()` / `reupload()` / `setItemStatus()`；
- 插槽：`default` / `preview-cover` / `preview-delete`。

主题新增 `$m-accordion-*`（17 项）、`$m-signature-*`（19 项）、`$m-slider-*`（19 项）、`$m-stepper-*`（20 项）、`$m-switch-*`（11 项）、`$m-uploader-*`（20 项），全部 `!default`。

## 三、修复

- **微信小程序日期滚轮列为空白**（[#31](https://github.com/MengXi-Studio/unix-ui/issues/31)）：`m-date-picker` → `m-picker` → `m-date-picker` 构成目录级循环依赖，HBuilderX 生成 `usingComponents` 时丢弃列组件注册。把内部滚轮列拆到独立目录 `m-date-picker-column/`，`m-picker` 与 `m-picker-view-column` 引用路径同步更新，产物恢复注册；
- **Android 云打包 Kotlin 编译错误**（15 处）：
  - 演示页带参事件处理器以 `function` 声明传值（accordion / switch），改为 `const` 箭头函数；
  - `resolve(null)` 与 `UTSPromise<Any>` 非空约束冲突（switch 演示页、uploader 串行上传链），改为 `resolve(true)` 并收敛为 `Promise<boolean>`；
  - `.catch((_: any) => ...)` 的 `any` 映射为非空 `Any`，与 `catch` 要求的 `(Any?) -> R` 不匹配（m-switch / m-uploader），改为无参 `.catch(() => ...)`；
  - `m-slider` 计算属性 `scales` 前向引用，`showScaleText` 提前到声明之前，改为先声明 `scales`；
  - 模板内联传入 `$event` 被推断为 `Any`（m-uploader 触摸开始、uploader 演示页插槽 `index`），在处理器内部显式收窄类型；
- **文档与源码对齐**：修正 30 余处 API 说明差异，包括 password-input-popup 缺失的 `shuffle()` 与三个插槽、cascader 的 `field-names.labelKey`、tabs 的 scrollspy 是否派发 `change`、toast 的 App 端 `wordBreak` 行为、grid / radio / space / flex 的子组件插槽、rate / search 的默认值口径、uploader / stepper / number-keyboard 的类型等，中英文双侧同步。

## 四、影响范围

- 新增组件仅新增文件与主题变量段，不修改既有组件默认行为；
- `m-date-picker-column` 由 `m-date-picker/` 迁至独立目录，属内部实现调整，对外 API 不变；如业务侧曾以相对路径直引该文件，需改为 `uni_modules/m-ui-x/components/m-date-picker-column/m-date-picker-column.uvue`；
- 主题变量均为新增，既有 `$m-*` 默认值未改动，用户覆盖契约不受影响。

## 五、验证

**微信小程序（HBuilderX 5.34，VDOM 模式）**

- `cli launch mp-weixin` 编译成功（74 页），产物 `usingComponents` 已包含 `m-date-picker-column`，日期 / 时间 / 农历滚轮列正常渲染；
- accordion / signature / slider / stepper / switch / uploader 六个演示页的变体、事件与插槽均可用。

**Android**

- `cli publish app-android --type appResource` 导出成功，逐条核对生成的 Kotlin：事件处理器均为局部 `val`、`catch(fun(){})` 无参、`resolve(true)`、`scales` 先声明后引用、触摸事件在处理器内收窄；
- 云端重新打包通过，安装包见文末资源区。

**工程校验**

- `pnpm sync:uni-modules` 与 `pnpm sync:uni-modules:check` 通过；
- `pnpm build:docs` 通过（中英文组件文档、侧栏与更新日志）。

**未覆盖**

- iOS / HarmonyOS / 支付宝等小程序未实测：代码已按条件编译适配，随版本复验；
- 签名组件在 Android 真机的手势绘制与导出效果，建议安装 APK 后复验。

## 六、从 0.7.x 升级

```bash
pnpm add @meng-xi/unix-ui@latest
# 将包内容拷贝覆盖 uni_modules/m-ui-x
```

- 无破坏性 API 变更，无需改业务代码；
- 若需新组件主题默认值，保持工程根 `uni.scss` 不 `@import` 主题文件即可（新增变量均为 `!default`）；
- 使用 `m-date-picker` / `m-picker` / `m-picker-view` 的项目请整体覆盖 `uni_modules/m-ui-x`，避免残留旧目录结构。
