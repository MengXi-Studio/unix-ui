# @meng-xi/unix-ui v0.8.1 发布：状态栏跨端高度修复与背景能力

> v0.8.1 是补丁版本，修复 `m-status-bar` 在微信小程序端无法自动占位的问题（[issue #33](https://github.com/MengXi-Studio/unix-ui/issues/33)），
> 并补上默认插槽与 `background` prop，便于状态栏与业务头部共享同一背景。无破坏性变更。

## 一、修复

**微信小程序端状态栏高度恒为 0**

- 现象：`navigationStyle: "custom"` 页面用 `m-status-bar` 占位时，微信小程序端高度为 0，导航内容顶进状态栏区域；
- 根因：系统高度读取包在 `#ifdef APP` 内，非 App 平台从未执行；
- 修复：改为在 `#ifndef WEB` 下读取 `uni.getWindowInfo().statusBarHeight`，App 与各小程序平台都走系统值，H5 保持 0（无系统状态栏）。

```vue
<!-- 微信小程序 / App：自动读取系统状态栏高度 -->
<m-status-bar />

<!-- H5：显式指定高度，或用 env(safe-area-inset-top) 控制 -->
<m-status-bar custom-style="height: env(safe-area-inset-top); background-color: #ffffff;" />
```

## 二、新增能力

**默认插槽**

插槽内容绝对铺满状态栏区域、不参与高度计算，可放背景层或沉浸式头图，与下方头部共享同一渐变。

```vue
<view class="hero">
	<m-status-bar :height="24">
		<view class="hero__bg"></view>
	</m-status-bar>
	<view class="hero__body">
		<text class="hero__title">沉浸式头图</text>
	</view>
</view>
```

**`background` prop**

根节点背景色，口径与 `m-tabs` 等组件一致；渐变仍通过 `custom-style` 设置。

```vue
<m-status-bar :height="32" background="#1989fa" />
<m-status-bar :height="32" custom-style="background: linear-gradient(90deg, #1989fa, #39b54a);" />
```

文档中文 / 英文双侧已同步，新增 API 以 `0.8.1` 徽标标注（页面级 `added` 仍为 0.3.0，记录组件首次收录版本）。

## 三、影响范围

- 仅调整系统状态栏高度的读取条件与模板结构，`height` / `custom-class` / `custom-style` 行为不变；
- 新增默认插槽对未使用插槽的页面无影响：内容层为空且绝对定位，不参与布局；
- 新增 `background` 为可选 prop，默认 `''`，不设置任何背景，既有页面视觉不变。

## 四、验证

- Web：`pnpm build:docs` 通过（中英文页面、`VersionBadge` 渲染正常）；
- `pnpm sync:uni-modules` 与 `:check` 通过；
- 微信小程序 / Android：代码已按 `#ifndef WEB` 适配，编译与真机占位效果需在 HBuilderX 打开后复验（本次会话 HBuilderX 无法启动，编译验证待补）；
- 未覆盖：iOS / HarmonyOS / 支付宝等小程序。

## 五、从 0.8.0 升级

```bash
pnpm add @meng-xi/unix-ui@latest
# 将包内容拷贝覆盖 uni_modules/m-ui-x
```

- 无破坏性 API 变更，无需改业务代码；
- 仅使用 `height` 的老页面可直接升级；需要背景同步的页面可改用 `background` 或默认插槽。
